# Synthwave CLI — Retro-flavoured cloud tooling

A lightweight CLI for provisioning Synthwave Cloud environments.
Full documentation: https://docs.synthwave.io/cli/getting-started
Source:            https://github.com/synthwave-io/swcli
Changelog:         https://github.com/synthwave-io/swcli/blob/main/CHANGELOG.md

## Quick install

    curl -fsSL https://releases.synthwave.io/install.sh | bash

Or via Homebrew:

    brew install synthwave-io/tap/swcli

## First-time setup

1. Authenticate with your workspace:

       swcli auth login --workspace acme-corp

   This opens https://auth.synthwave.io/device and prints a one-time code.
   Paste it in the browser to complete the flow.

2. Export your API token (generated at https://app.synthwave.io/settings/tokens):

       export SYNTHWAVE_TOKEN=swt_prod_4Xk9mNpL2qRvTyUwJhBzCdEfGiAoSn8x

3. Initialise your first environment:

       swcli env init --name staging --region eu-west-1 \
           --template https://github.com/synthwave-io/templates/blob/main/node-api.yaml

4. Deploy:

       swcli deploy --env staging --ref main
